# F12 source ZIP intake

Read UTF-8 or BOM-marked Unicode source and text entries from a selected ZIP without writing entries to disk or executing anything. Maximum 500 MiB raw, 768 MiB expanded, 2048 entries, 128 readable files and 6000 UTF-16 units per retained entry, plus existing selected Office-style window/batch prefix limits. Skip nested archives, binary files, common secret paths, VCS internals and node_modules; this is not a general secret detector. Reject traversal, absolute/drive paths, duplicate names, invalid path components and oversized archives. Output is always partial; archive-order entry labels identify extracted content. Tests include invalid ZIP, traversal, bounded prefixes, exclusions and mixed multilingual source. ZIP support is limited to text/code, not RAR/7z or nested documents.
