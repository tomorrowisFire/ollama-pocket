# On Hands AI v0.12.0 development candidate

Base: cd12614132c6951e215be387738b0beafa4e7599. Main branch unchanged. Package ID and existing model/history keys preserved.
Implemented: app display name; 81 common/new UI resource keys across English, Korean, Simplified Chinese, Traditional Chinese and Japanese; in-app locale picker; chat composer with on-device speech recognition (Android 12+ and installed language service), local-only TTS; separate single-turn BYOK cloud UI for six fixed HTTPS providers; dedicated compute-only guest screen using the existing encrypted RPC worker. Release advertising is disabled by the BuildConfig.DEBUG gate; no production ad requests or publication authorized.

Limitations: legacy settings, model catalogs, diagnostics, service notifications and errors still contain Korean literals. Full localization, native screen/device checks, real cloud requests, offline voice language pack tests, zero-model two-device guest execution, RPC memory/thermal/cache verification, Markdown renderer and provider-specific feature support are pending. No API keys are persisted or requested automatically. API usage can incur charges. Existing API 35 build configuration is retained for this isolated development candidate; the prior Play/AAB work and full AdMob safety patch must be integrated and verified separately before submission. Current cloud screen is single-turn, not an automatic fallback from local chat. No PC remote connector yet. Do not treat this branch as a Play release.
