# F5C2 frozen KPI — durable explicit local conversation references
Baseline f1d10a03b572ee488cf632811f5db9d50c06734f F5C1 accepted. A/B/C simulated roles.
A (UX): from a normal private project workspace, explicitly link the current saved local conversation, display model/session identity, review before save and before opening. Show missing, unreadable and unavailable-model states; never create a replacement conversation or install a model. Remove only the reference with confirmation; project deletion removes its references, never conversation data. Link other saved chats by opening them first. No automatic context, transfer or inference.
B (engineering): store model + numeric session ID only (no title/message/draft copy) in same reviewed project transaction, max 12 per project, no duplicates. Old canonical schema 1 remains byte-identical when no links; schema 2 canonical when links exist, strict decode and same 2 MiB bound. Project edits/artifact operations preserve links; delete project atomically removes links. Older app versions cannot read schema 2; no destructive downgrade. Validate persisted local index unique exact model/session and existing readable bounded history; distinguish missing and corrupt; link current loaded saved scope only, recheck on explicit add and open; open using existing local chat navigation only after project/source revalidation and foreground gate. No implicit chat or project mutation aside from explicit save and existing draft-preserving navigation.
C (quality): all five locales; tests for v1 exact compatibility, v2 canonical and tamper rejection, identity/duplicate/bounds, preservation/deletion, missing/corrupt source, scoped transaction conflict. CI exact Java and native APK/QA AAB/16 KiB/ad/locale/regression required. No changes to permissions, package, signing, ads, engine or cloud.
