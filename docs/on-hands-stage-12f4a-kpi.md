A: conference entry in Automation menu, goal, selected model, explicit user-chosen validator/condition, review before Start; show each completed role turn and current artifact, issue, predicate result and attempted calls. Cancel and copy transcript with explicit consent. Partial/blocked states clearly labeled, no automatic application or persistent storage.

No external tools. Same local CPU model, <=5 chat requests, <=5 min monotonic analysis deadline, <=512 output tokens and <=4000 UTF-16 reply per call, existing 2048 context estimate with fail-closed preflight every call. Goal <=240 UTF-16, plan <=300, artifact <=600, review issues <=200. Condition uses existing 6 validators, <=200 including serialized directive per existing parser; user sets condition, AI cannot replace it. Strict JSON role shapes plan:string; artifact:string; decision:string,issues:string with exact ACCEPT/REVISE, nonempty issues for REVISE. Preserve exact artifact for predicate, bind review to current artifact; wrap all input data as JSON in prompts, no silent truncation. On context overflow or invalid/truncated response fail with partial transcript; no blind retry.
C: completion requires actual configured predicate MATCH plus model's ACCEPT for the same current artifact, NOT factual verification or independent quality approval. Model recommendation cannot bypass predicate. Zero further calls after terminal; STOPPED on cancel/deadline/safety; no successful turn accepted after observed stop. No checkpoint schema/storage/permissions/endpoint or external action changes. Foreground cancellation and watchdog, bounded transport, explicit sensitive clipboard consent. Prior completed turns retained in memory until dialog closed; no recovery across process death in F4A. F4B may extend transcript export and UX/handoff after verification.
