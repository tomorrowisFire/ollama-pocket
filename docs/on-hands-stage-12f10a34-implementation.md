Added pure Java ToolCallApproval, separate from the existing LAN client and UI. Each session accepts one pending review with a two-minute monotonic lifetime. The fingerprint covers exact validated endpoint, tool name, opaque refreshed catalog identity and strict raw JSON arguments, using length-framed SHA-256 of UTF-16 code units. No raw argument body is retained in the guard. Preparing another request or revoking/declining invalidates the pending review. User approval is single-use; mismatched final arguments/endpoint/catalog or a failed eligibility/permission/schema recheck consume the approval without starting a call. Atomic synchronized admission permits one outstanding lease, 1–16 admitted attempts per session, no budget refund after admission even on an uncertain failure, and no automatic replay. Closing or revoking the guard does not falsely release an active transport lease. The future integration must still bind the exact displayed text and explicit user action, validate private endpoints and schema/eligibility, recheck permission/catalog, and cancel/release the actual transport correctly. This module alone is not transport enforcement.
