# F12 deep-chat access policy

Normal attachment limits remain one file per selection, plain text 1 MiB, structured documents/images/PDF 8 MiB and 256 segments. The deep workspace uses the expanded file/batch budgets. A successful SDK reward event on the exact displayed ticket grants 30 minutes from monotonic elapsed time; renewals reset rather than stack time. One pending ticket, duplicate/stale callback rejection, no reward on dismissal/load alone. Process-local grant survives Activity recreation, not process death or reboot; no wall-clock manipulation. Test-verified purchase ownership exempts the reward requirement. Expiry blocks new deep runs, not an admitted foreground analysis or its report. Existing cancellation/thermal/runtime rules still apply. No production entitlement verification claim.
