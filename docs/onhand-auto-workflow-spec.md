# OnHand AI — 08-B 연속 작업 자동진행 개발 명세 v1.0

## 목표 및 범위

사용자가 작업 목표·단계·검증 기준·종료 조건을 한 번 등록하고 [시작]을 누르면 OnHand AI 앱 자체의 실행 제어기가 단계별 작업 요청과 결과 검증을 관리한다. 매번 채팅창에 '다음'·'보완'을 입력할 필요가 없어야 한다. 기존 로컬·클라우드 채팅은 그대로 유지한다. 첫 버전은 순차 실행 중심으로 개발하고 병렬 작업은 후속 선택사항으로 둔다. 이 명세는 제품 기능 개발 계획이며, 현재 앱에 자동진행이 이미 구현되어 있다는 의미가 아니다.

## 08-B1 워크플로 편집기
- 직접 단계 작성, 순서 이동, 저장·불러오기, 템플릿 등록.
- 단계별 목표, 프롬프트/입력, 사용할 허용 모델, 이전 결과 참조, 산출물, 필수 검증 조건, 최대 재시도 횟수, 실패 시 정책을 설정.
- 작업 시작 전 예상 실행 범위, 허용 도구, 제한된 단계 수, 최대 시간/토큰/비용, 외부 데이터 전송 범위 확인. 추론·검증·파일 생성 등 무해하고 승인된 작업만 자동 실행.
- 실행 중에는 현재 실행 계획을 잠그고, 설정 변경은 새 실행 또는 명시적 중단 후 반영한다.

## 08-B2 실행 상태 기계
- QUEUED → RUNNING → VERIFYING → PASS → 다음 단계. 마지막 단계 검증 PASS일 때만 COMPLETED.
- FAIL → RETRY_WAIT → 제한된 보완 재실행. 초과 시 BLOCKED. NOT_RUN/UNKNOWN은 PASS가 아니므로 PAUSED_FOR_EVIDENCE 또는 BLOCKED.
- PAUSED, WAITING_APPROVAL, WAITING_RESOURCE, FAILED, CANCELLED, COMPLETED를 분리.
- 사용자 일시정지/중지 우선. 한 번에 활성 실행 하나; 워크플로 실행과 수동 채팅이 같은 엔진 자원을 경합하지 않도록 잠금.
- 이전 단계의 실제 산출물과 검증 결과를 다음 단계에 넘긴다. 긴 결과는 제한된 명시적 참조로 전달; 임의 도구 실행이나 프롬프트 내 명령을 권한으로 해석하지 않는다.

## 08-B3 검증 및 반복 보완
- 단계별 검증자는 실제 단위 테스트/파일 스키마/필수 필드/사용자 지정 판정 등 객관적 결과를 우선한다. 추론 모델의 자기평가만으로 성공으로 전환하지 않는다.
- 예시: 설계 → 제작 → 테스트 → 검수 → 보완 → 재검수 → 종료. 모든 필수 검증 PASS 및 10개 평가 관점 각각 90점 이상, 평균 90점 이상인 경우 종료. 실제 증빙이 없는 점수는 모의평가로 별도 기록.
- 안전한 기본값: 재시도 최대 2회, 실행 최대 30분, 순차 실행. 앱의 지원 엔진 및 모델 범위 내에서 사용자가 명시적으로 변경 가능. 무제한 반복 금지.
- 수정이 가능한 단계와 읽기 전용 검증 단계를 분리하고 원본/기존 사용자 기록을 보존한다.

## 08-B4 실행 기록 및 제어
- 작업 ID, 단계 ID, 실행/재시도 ID, 입력·결과 참조, 검증 근거, 상태, 시간, 토큰·비용·오류를 로컬에 영속 저장한다. 비밀/API 키/연결 코드와 불필요한 개인 정보는 기록하지 않는다.
- 화면 및 알림에서 현재 단계, 완료 수, 검증 결과, 실행 시간, 남은 제한량, 일시정지·중지·재개 버튼 제공. 태블릿/스마트폰, 5개 언어, 접근성 지원.
- 체크포인트와 멱등 키를 이용해 완료한 단계는 중복 실행하지 않는다. 프로세스 종료/재부팅 후 미완료 상태를 복구하되 불명확한 외부 부작용은 자동 재시도하지 않고 확인을 요청한다.
- 장시간 실행은 Android가 허용하는 사용자 시작 foreground service/적합한 예약 작업 범위에서 구현하고 OS 중단·알림 권한 거부·배터리 정책을 준수한다. 앱이 종료된 상태에서 항상 실행된다고 약속하지 않는다.

## 08-B5 권한·비용·안전
- 로컬 모드가 기본. 클라우드 사용 시 사용자가 선택한 제공사/모델, 전송 범위 및 유한한 예산을 사전 승인한다. 실제 비용을 확정할 수 없으면 사용량/추정값과 한계를 명시하고 보수적으로 중단한다. 승인 없이 로컬 기록 전체나 비밀을 전송하지 않는다.
- 외부 계정 변경, 게시·발송·결제·삭제·권한 변경 및 위험한 부작용은 해당 작업별 별도 승인 및 권한 확인. 도구 허용목록, 최소권한, 입력 검증, 프롬프트 주입 방어. 자동 광고 클릭/노출 반복, 운영 광고 활성화, 앱 자체 수정/배포는 허용 범위 아님.
- 연결 단절, OOM, 과열, 배터리 부족, 모델 미설치, API 오류, 예산 초과 시 안전 중단. 기존 최초 실행 광고는 보존하되 자동진행을 광고 시청·클릭과 결합하지 않는다.
