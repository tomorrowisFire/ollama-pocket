Existing local CPU, manual MCP permissions, schema, history, model/ad boundaries unchanged. Report legacy counters as previously incomplete; no invented historical usage. Use deterministic fixtures for all six validators, legacy, Unicode and truncation; verify time and attempt caps, terminal/invalid states and stale snapshot/draft/model matching.
