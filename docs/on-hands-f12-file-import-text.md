# F12 file intake — plain source module

16 MiB raw text cap, 4096 UTF-16 windows; stream and validate all bytes while retaining only the chosen window or bounded batch prefix. Expanded explicit allowlist for common code, config, data, markup, build and subtitle text formats; no execution, rendering, external links or automatic transfer. Office retains a separate 256-window budget. Tests include legacy encodings, exact cap, late malformed bytes, large late windows and unsupported binaries. Large file analysis is still excerpt-based; not a larger LLM context.
