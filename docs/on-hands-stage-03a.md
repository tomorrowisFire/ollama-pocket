# OnHand AI — Stage 03-A local conversation candidate

Base ef162e6d6af54e8343ce8fc779c892e044d1e265. Adds local question editing and answer regeneration as explicit new conversation branches. Original stored message arrays and later answers are unchanged. New branch copies only history before selected user message. Local request context consists of recent complete adjacent user/assistant pairs plus one current question; legacy orphan messages stay in stored history. Completed response requires normal CPU done or GPU SSE terminal signal. Cancelled, failed, empty and incomplete turns do not enter completed history; prompt is retained as local draft and incomplete visible text may be copied. Commit of a completed pair and index uses one SharedPreferences editor; disk-write crash durability is not certified. Old history format, names and keys remain. Removed previous silent 32-message history truncation; storage is bounded at 256 entries/512000 serialized characters per conversation for new additions, context is bounded at 15 pairs/48000 characters, existing engine token limits remain. Existing larger or corrupted histories are not overwritten. New conversation writes an explicit empty array to avoid unintended legacy re-import. Explicit branch requires installed model for automatic generation; if unavailable draft remains. Device and lifecycle tests still NOT_RUN; actual UI and engine success must be observed. Cloud panel is unchanged; cloud editing/regeneration and advanced Markdown/export are later candidates. Five locales (637 keys). First-run ad source and production lock unchanged. Stage 01/02 remain pending real-device gates; 03-A is preparatory implementation, not official approval.

The loaded history scope and actual persisted JSON snapshot are checked before publishing a completed turn or creating a branch.
