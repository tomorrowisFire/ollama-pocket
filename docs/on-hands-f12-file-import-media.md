# F12 file intake — media budgets

PDF: 64 MiB disk-streamed input with 16 MiB free-space reserve and original isolated parser, page, excerpt and timeout guards. OCR/VLM source image limit 16 MiB, original pixel and output limits retained. VLM remains JPEG/PNG only, OCR JPEG/PNG/WEBP. Android 15+ PDF requirement unchanged. These are admission limits, not evidence that every device can process every admitted file; device memory/storage and actual file contents can prevent processing.
