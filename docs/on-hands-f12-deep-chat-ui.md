# F12 mode separation

Separate Normal and Deep tabs on the local chat screen. Normal chat retains its existing history and draft, single inserted attachment and old 1/8 MiB limits enforced on actual source streams; normal OCR and standalone VLM remain single-file and 8 MiB. Deep tab is a separate reviewed document-analysis workspace, not a shared conversation history; choose up to 20 files/2 GiB, 500 MiB each. All batch entry points route through the same access check (entry, picker return, analysis confirmation). A process-local 30-minute pass can be renewed explicitly; valid test purchase grants unlimited access. Once admitted, foreground analysis and report review/export do not recheck pass expiry; existing user cancellation, app lifecycle, memory/thermal/time controls remain. No extra ad during a running job. When expired, save/close the workspace and renew before another run. No automatic ads. Real device/layout and billing/ad tests pending.
