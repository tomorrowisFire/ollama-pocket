The runtime contains its own statically linked ggml CPU backend. It is isolated
from the app's language-model runtimes. No cloud recognition service is used.

Optional model: OpenAI Whisper tiny, multilingual, converted by ggerganov.
Model source: https://huggingface.co/ggerganov/whisper.cpp/tree/fb5ed9369c26eaf08392504d8446da431e0fffb9

This UI enables Korean, English, Japanese and Chinese recognition. Simplified
and Traditional Chinese both select Whisper's zh language; the model does not
guarantee a particular output script. Accuracy, latency and power use depend
on the recording and device. Downloading the optional model requires network;
installed-model recognition processes microphone audio locally and does not
save recordings. Recordings are bounded to 30 seconds. Cancellation during a
model load discards the result and releases the context after loading returns.
